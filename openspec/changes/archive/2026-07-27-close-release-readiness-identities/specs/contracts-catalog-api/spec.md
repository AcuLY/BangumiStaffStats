## ADDED Requirements

### Requirement: Catalog Go replay SHALL have a closed offline module identity

The Catalog owner gate SHALL declare, materialize, and compile its temporary Go
module with exactly `github.com/oapi-codegen/runtime v1.1.2` and
`github.com/google/uuid v1.6.0`, where the UUID version is the accepted higher
version already present in the sealed Backend Go closure. The ordered
requirement set SHALL be recorded in generation evidence and checked before
the command starts. Public network, ambient module cache bytes, a lower
transitive version, or an undeclared replacement SHALL not satisfy the gate.

#### Scenario: Sealed module closure is available
- **WHEN** both exact module versions are present in a fresh owner cache and public network is denied
- **THEN** both generation replays and the temporary compile SHALL pass with identical generated bytes

#### Scenario: Closure declaration or cache bytes drift
- **WHEN** either required module/version is changed, omitted, substituted, or unavailable
- **THEN** the Catalog owner gate SHALL fail and clean its disposable output
