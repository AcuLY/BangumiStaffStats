| Item | Contract |
|---|---|
| Owner | Delegated Query Contracts owner implements and verifies groups 1-2; main agent reviews specs, audits findings, marks tasks and owns lifecycle. |
| Writable implementation | `contracts/goldens/query/{verify.mjs,manifest.json}`, `contracts/goldens/query-domain/{verify.mjs,manifest.json}`, `contracts/goldens/statistics/index.json` only. |

## 1. Query owner implementation

- [ ] 1.1 Preflight branch/HEAD, clean index, allowed dirty inventory, exact
  writable complement, strict OpenSpec and protected authority hashes.
- [ ] 1.2 Add `deny network*` to the single approved Go sandbox profile, update
  its exact SHA-256, and keep the wrapper, `env -i`, argv, cwd, tool identities,
  module inputs and all other environment values unchanged.
- [ ] 1.3 Extend/execute the existing profile and wrapper drift coverage so
  omission, reordering, text/digest mismatch or use by fewer than all four Go
  children fails before acceptance.
- [ ] 1.4 Recompute only necessarily affected Query manifest evidence and
  verifier self-identity; prove module locks, module graph, TypeScript and Go
  generated bytes are unchanged.
- [ ] 1.5 Rebind only Query Domain's Query-manifest authority plus resulting
  verifier self-identity, then only Statistics' Query Domain handoff SHA-256.

## 2. Query owner verification

- [ ] 2.1 Run the locked full Query flow twice in the original checkout and
  once from each of two distinct canonical absolute clone roots. Record four
  inner Go children per run, the exact new profile text/digest, identical
  generated hashes, cleanup success and physical zero residue.
- [ ] 2.2 Run Query Domain, Statistics, Backend and Frontend Query drift gates;
  run syntax/JSON, strict OpenSpec, diff/seal and protected-input checks.
- [ ] 2.3 Hand off unstaged with an empty index, exact changed-pointer/file
  inventory, no generated residue and no ref/external-state mutation.

## 3. Main-agent audit and lifecycle

- [ ] 3.1 Audit the implementation and evidence for zero P0/P1, independently
  verify the exact five-file writable complement and unchanged generated/module
  outputs, and mark completed tasks.
- [ ] 3.2 Sync the delta into `contracts-query-wire`, archive and strictly
  validate the change, commit/push the lifecycle result, then resume the
  acceptance Harness companion correction and Product/Harness reseal.
