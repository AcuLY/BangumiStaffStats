## Context
User expressly requests NTag for all rendered tags. PersonInspector and CoStarSurface grouped evidence already use NTag small round; role and work metadata pills plus candidate identity chips remain custom. QueryEditor uses NDynamicTags, which internally renders NTag. Rank ordinals, links, text status and radio/button groups are not tags.
## Goals / Non-Goals
Unify actual tag surfaces and center labels. Retain semantics, canonical data, 2-row adaptive packing, complete overflow access, identity removal/focus, theme and mobile layout. No query behavior, contracts, dependencies or backend work.
## Decisions
Neutral role/metadata/evidence tags use NTag size=small round (22px in current theme), default neutral theme colors. Selected identity tags retain primary semantic coloring, with accessible removal and existing 44px interaction target; no nested interactive controls. Do not hand-paint NTag border/background or override its internal nodes. Measurement copies and tooltip tags match actual nodes. Group rows align-items:center, labels margin:0. When tags wrap, labels center on their row's tag block. Retain NSkeleton for placeholders and align its geometry, never replace loading placeholders with real tags.
